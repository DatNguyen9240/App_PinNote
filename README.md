# IELTS Corner - Tiện ích & Ứng Dụng Học IELTS & Note Tối Giản

Phiên bản nâng cấp mới đáp ứng trọn vẹn tất cả yêu cầu:
1. **🪟 Nắm kéo tab tách Note ra ngoài riêng (Tear-off Window)**: Nắm giữ chuột vào tab Note và kéo ra ngoài màn hình để tách thành một cửa sổ nổi độc lập! Hoặc bấm nút `[↗]` để tách tức thì. Ở cửa sổ riêng bấm `[↙]` để gộp lại vào cửa sổ chính.
2. **🌐 Dịch chuẩn ngữ cảnh IELTS (Ctrl + T)**: Dịch câu/đoạn văn học thuật mượt mà, phân tích các nét nghĩa và từ loại theo ngữ cảnh IELTS.
3. **📑 Tạo & Quản lý nhiều Note cùng lúc**: Thêm nhanh bằng nút `[+]` hoặc `Ctrl + N`, nhấp đúp đổi tên Note (VD: `Task 1`, `Task 2`, `Collocations`), chuyển tab `Ctrl + Tab`.
4. **🖍️ Highlight thông minh + Hoàn tác `Ctrl + Z`**: Bôi đen chữ ấn `Ctrl + H` để highlight, vừa highlight xong ấn `Ctrl + Z` là mất màu ngay mà không mất chữ.
5. **👁️ Tối ưu hiển thị (Zen Mode & Split View)**: Xem được nhiều chữ và hình cùng lúc với chế độ song song **[🌓 Cả hai]**, thanh cuộn mỏng 5px, ẩn thanh nút để tối đa diện tích.
6. **🚫 Không còn dấu gạch đỏ ziczac**: Đã tắt triệt để tính năng spellcheck kiểm tra chính tả.
7. **📌 Luôn nổi trên màn hình (Always-on-top)**: Hiển thị nổi trên màn hình ở bất cứ đâu (đè lên Word, PDF Cambridge, Chrome, Desktop...) mà không bị giới hạn trong trình duyệt.

## 🎯 3 Cách Sử Dụng IELTS Corner:

### 🌟 CÁCH 1: Ứng dụng Desktop chạy ở bất cứ đâu trên màn hình (Khuyên dùng)
- **Vị trí file chạy**: [Chay_App_IELTS_Corner.bat](file:///d:/Dat/extention_ielts/Chay_App_IELTS_Corner.bat)
- **File mã nguồn**: [app.py](file:///d:/Dat/extention_ielts/desktop_app/app.py)
- **Cách dùng**: Nhấp đúp chuột vào file `Chay_App_IELTS_Corner.bat` (có thể chuột phải -> Send to Desktop để tạo biểu tượng ngoài màn hình chính).
- **Tính năng nổi bật**:
  - **Nắm kéo tách Note ra ngoài riêng (Tear-off Window)**: Nhấp giữ chuột vào tab Note và kéo ra ngoài màn hình (hoặc bấm biểu tượng `[↗]`) để tách Note thành một cửa sổ nổi độc lập. Ở cửa sổ riêng bấm `[↙]` để gộp trở lại cửa sổ chính.
  - **Dịch chuẩn ngữ cảnh (Ctrl + T)**: Bôi đen đoạn văn/từ vựng bất kỳ rồi ấn `Ctrl + T` (hoặc icon 🌐). Khung dịch sẽ trượt lên hiển thị bản dịch học thuật và từ điển ngữ cảnh. Bấm `📋 Sao chép` hoặc ấn `Esc` / `✕` để đóng.
  - **Quản lý nhiều Note**: Bấm `[+]` tạo Note mới, nhấp đúp vào tên Note để sửa tên.
  - **Highlight 4 màu (Ctrl + H)**: Vàng, xanh lá, hồng, xanh lam.
  - **Undo Highlight (Ctrl + Z)**: Ấn `Ctrl + Z` để hủy màu highlight tức thì.
  - **Always-on-top**: Nổi đè lên Microsoft Word, Foxit/Acrobat Reader PDF, Chrome, PowerPoint... Có nút **📌 Ghim** để bật/tắt.
  - **3 Chế độ xem linh hoạt**: `📝 Văn bản`, `🖼️ Hình ảnh`, `🌓 Cả hai` (vừa nhìn đề bài vừa gõ bài làm).
  - **Đọc phát âm (TTS)**: Phát âm tiếng Anh chuẩn bản xứ (`Ctrl + D` hoặc nút `🔊`).

### 🧩 CÁCH 3: Tiện ích Chrome / Edge Extension (Trên mọi trang web)
Nếu bạn đang lướt web và muốn widget hiển thị nổi ở góc trang:
1. Mở Chrome gõ `chrome://extensions` (bật **Developer Mode**).
2. Bấm **Load unpacked** (Tải tiện ích đã giải nén) và chọn thư mục `d:\Dat\extention_ielts`.
3. Widget nổi góc màn hình đã được nâng cấp:
   - Nút **[🌐 Dịch]** và phím tắt `Ctrl + T` dịch chuẩn ngữ cảnh ngay trong widget.
   - Nút **[🖍️]** và phím tắt `Ctrl + H` để highlight, `Ctrl + Z` để hoàn tác highlight.
   - Tab **[🌓 Cả hai]** hiển thị song song cả ảnh và chữ.
   - Nút **[🔽]** trên góc phải giúp giấu thanh công cụ bên dưới để mở rộng diện tích xem chữ và ảnh tối đa.
   - Hoàn toàn không còn dấu gạch đỏ dưới chân chữ.
